# Что нового

## Лента обновлений и профиль

- Смена аватара пользователя теперь пушится в ленту обновлений: событие сразу применяется в ленте на всех устройствах.
- Обновление аватара в профиле перенесено в отдельную функцию формы — логика применения события в ленте упрощена.
- Смена папок (создание, удаление, перенос канала) пушится в личную ленту устройств: список папок обновляется на всех открытых клиентах без перезагрузки.

## Лента событий

- Догонка ленты больше не останавливается на некорректных событиях — они пропускаются, а обновления продолжают применяться.
- В превью последнего сообщения темы поддерживаются стикеры и цвет отображения «Вы».

## Трансляции

- Форма просмотра трансляции показывает реальную статистику WebRTC: сбор метрик соединения, обновление в реальном времени, корректная остановка плеера.

## Исправления

- Получение информации об канале отдаёт полный объект — превью канала больше не вымывается.
